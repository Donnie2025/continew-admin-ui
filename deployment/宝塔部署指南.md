# continew-admin-ui 宝塔面板部署指南

## 📋 前置条件

- 已安装宝塔面板
- 已安装Nginx
- 服务器已配置域名解析（可选）

## 🚀 部署步骤

### 第一步：创建网站

1. **登录宝塔面板**
   - 访问你的宝塔面板地址（通常是 `http://服务器IP:8888`）
   - 使用管理员账号登录

2. **添加站点**
   - 点击左侧菜单 `网站` → `添加站点`
   - 填写配置信息：
     ```
     域名: admin.yourdomain.com（或直接使用IP）
     根目录: /www/wwwroot/continew-admin-ui
     FTP: 不创建
     数据库: 不创建
     PHP版本: 纯静态（不需要PHP）
     ```
   - 点击 `提交` 创建站点

### 第二步：上传构建文件

#### 方法一：使用宝塔文件管理器

1. **上传压缩包**
   - 点击左侧菜单 `文件`
   - 进入 `/www/wwwroot/continew-admin-ui` 目录
   - 点击 `上传` 按钮
   - 选择本地的 `continew-admin-ui-dist-xxxxxx.tar.gz` 文件上传

2. **解压文件**
   - 右键点击上传的压缩包
   - 选择 `解压`
   - 解压完成后删除压缩包文件

#### 方法二：使用SCP命令（推荐）

```bash
# 在本地执行
scp continew-admin-ui-dist-20260116-112700.tar.gz root@113.44.176.51:/www/wwwroot/continew-admin-ui/

# SSH连接到服务器
ssh root@113.44.176.51

# 进入网站目录
cd /www/wwwroot/continew-admin-ui

# 解压文件
tar -xzf continew-admin-ui-dist-20260116-112700.tar.gz

# 删除压缩包
rm continew-admin-ui-dist-20260116-112700.tar.gz
```

### 第三步：配置Nginx

1. **编辑站点配置**
   - 在宝塔面板中，点击 `网站` → 找到你的站点
   - 点击 `设置` → `配置文件`
   - 将配置文件内容替换为：

```nginx
server {
    listen 80;
    server_name admin.yourdomain.com;  # 改为你的域名或IP
    index index.html;
    root /www/wwwroot/continew-admin-ui;
    
    # 启用gzip压缩
    gzip on;
    gzip_vary on;
    gzip_min_length 1024;
    gzip_comp_level 6;
    gzip_types
        text/plain
        text/css
        text/xml
        text/javascript
        application/javascript
        application/xml+rss
        application/json;

    # 静态资源缓存
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
        access_log off;
    }

    # SPA路由支持 - 重要！
    location / {
        try_files $uri $uri/ /index.html;
    }

    # API代理（根据你的后端地址调整）
    location /api/ {
        proxy_pass http://localhost:8000/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 60s;
    }

    # 安全头
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-XSS-Protection "1; mode=block" always;
    add_header Referrer-Policy "strict-origin-when-cross-origin" always;

    # 禁止访问敏感文件
    location ~ /\. {
        deny all;
    }
    
    location ~ \.(sql|log|conf)$ {
        deny all;
    }

    access_log /www/wwwlogs/continew-admin-ui.log;
    error_log /www/wwwlogs/continew-admin-ui.error.log;
}
```

2. **保存并重载配置**
   - 点击 `保存`
   - 宝塔会自动重载Nginx配置

### 第四步：设置文件权限

1. **在宝塔文件管理器中**
   - 进入 `/www/wwwroot/continew-admin-ui` 目录
   - 全选所有文件和文件夹
   - 右键选择 `权限`
   - 设置权限为 `755`
   - 勾选 `应用到子目录`
   - 点击 `确定`

2. **或者使用SSH命令**
```bash
cd /www/wwwroot/continew-admin-ui
chown -R www:www .
chmod -R 755 .
```

### 第五步：验证部署

1. **检查文件结构**
   确保网站根目录 `/www/wwwroot/continew-admin-ui` 包含：
   ```
   /www/wwwroot/continew-admin-ui/
   ├── index.html
   ├── static/
   │   ├── js/
   │   ├── css/
   │   └── [其他静态资源]/
   └── [其他构建文件]
   ```

2. **访问网站**
   - 浏览器访问：`http://你的域名` 或 `http://服务器IP`
   - 检查页面是否正常加载

## 🔧 高级配置

### SSL证书配置

1. **申请SSL证书**
   - 在宝塔面板中，点击站点 `设置` → `SSL`
   - 选择 `Let's Encrypt` 免费证书
   - 填写邮箱地址
   - 点击 `申请` 

2. **强制HTTPS**
   - 证书申请成功后
   - 开启 `强制HTTPS` 选项

### 性能优化

1. **开启页面缓存**
   - 点击站点 `设置` → `缓存`
   - 开启 `页面缓存`
   - 设置缓存时间为 `1小时`

2. **开启防盗链**
   - 点击站点 `设置` → `防盗链`
   - 根据需要配置防盗链规则

### 安全设置

1. **配置防火墙**
   - 点击 `安全` → `防火墙`
   - 确保开放 `80` 和 `443` 端口

2. **设置访问限制**（可选）
   - 点击站点 `设置` → `访问限制`
   - 可以设置IP白名单或黑名单

## 🔍 故障排查

### 常见问题

1. **页面显示404**
   - 检查 `try_files $uri $uri/ /index.html;` 配置是否正确
   - 确认 `index.html` 文件存在

2. **静态资源加载失败**
   - 检查文件权限是否正确
   - 查看Nginx错误日志：`/www/wwwlogs/continew-admin-ui.error.log`

3. **API请求失败**
   - 检查后端服务是否正常运行
   - 确认API代理配置中的地址是否正确

4. **刷新页面404**
   - 这是SPA应用的常见问题
   - 确保Nginx配置中有 `try_files` 规则

### 日志查看

1. **访问日志**
   ```bash
   tail -f /www/wwwlogs/continew-admin-ui.log
   ```

2. **错误日志**
   ```bash
   tail -f /www/wwwlogs/continew-admin-ui.error.log
   ```

3. **Nginx状态**
   ```bash
   systemctl status nginx
   ```

## 📱 移动端适配

项目已支持响应式布局，在宝塔面板中无需额外配置即可在移动设备上正常访问。

## 🔄 更新部署

当需要更新网站时：

1. 本地执行 `npm run build`
2. 运行 `./package-dist.sh` 生成新的压缩包
3. 上传新的压缩包到服务器
4. 备份当前版本（可选）
5. 解压新版本覆盖旧文件
6. 清理浏览器缓存测试

## 📞 技术支持

如果遇到问题：
1. 检查宝塔面板的系统日志
2. 查看Nginx配置是否正确
3. 确认文件权限设置
4. 检查防火墙和安全组设置
